EEG-Based Cognitive Load Estimation using NSGA-II and EEGNet

This project focuses on estimating cognitive load from EEG (Electroencephalogram) signals using a hybrid approach that combines:
->Multi-objective evolutionary optimization (NSGA-II) for optimal EEG channel selection
->EEGNet, a lightweight deep learning model for EEG signal classification
The goal is to improve classification performance while reducing the number of EEG channels, making the system more efficient and practical for real-world applications.
